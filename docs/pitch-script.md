# Relay — 1-minute pitch script

**0:00-0:12**

AI agents can think and act, but they cannot pay for what they need without a human approving it.

> AIエージェントは考え行動できますが、支払いには人間の承認が必要です。

**0:12-0:28**

That blocks true autonomy. Agents need to pay for APIs, data, and compute, instantly and on their own.

> これが完全な自律性を妨げます。エージェントはAPIやデータ、計算資源の支払いを自分自身で即座に行う必要があります。

**0:28-0:45**

Relay is a Solana protocol where agents open payment streams, settle per-call micropayments in stablecoins, and build on-chain reputation.

> Relayは、エージェントが支払いストリームを開き、呼び出しごとにステーブルコインで決済し、オンチェーンの評判を築けるSolanaプロトコルです。

**0:45-0:55**

No humans, no invoices, just agents transacting with agents, trust built directly on-chain.

> 人間もインボイスも不要。エージェント同士が取引し、信頼はオンチェーンに直接構築されます。

**0:55-1:05**

We built the wallet SDK, escrow program, reputation registry, and a marketplace demo. This is payment rails for the agent economy.

> ウォレットSDK、エスクロープログラム、評判レジストリ、マーケットプレイスのデモを構築しました。これがエージェント経済のための決済インフラです。
